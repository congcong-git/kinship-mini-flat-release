# 亲戚叫得准

微信小程序。输入两个人与「我」的关系，算出双方该怎么互相称呼。

## 特点

- **纯本地计算**：零网络请求、零存储、零登录，整包约 50 KB
- **双向互称**：不只算「我怎么叫他」，也算「他怎么叫我」
- **长幼不混**：伯与叔是两个不同的人，路径推不出长幼时单独注明条件，不当成同义词并列
- **附字源**：堂舅、表伯父这类容易混的称谓，给出《尔雅·释亲》原文与白话解释

## 怎么用

1. 微信开发者工具 → 导入项目 → 选本目录
2. 直接编译

`project.config.json` 里的 AppID 是开发者的，fork 之后请改成你自己的，否则会提示无权限。

## 核心设计

关系用 8 个 token 组成的路径表示，任意深度的关系都能拼出来，不需要穷举词表：

| token | 含义 | | token | 含义 |
|---|---|---|---|---|
| `F` | 父 | | `S` | 子 |
| `M` | 母 | | `D` | 女 |
| `B` | 兄 | | `W` | 妻 |
| `R` | 姐 | | `H` | 夫 |

```
M·B·S      舅家的孩子        → 表哥
F·F·B·S    祖父兄弟的儿子    → 堂伯父
M·F·B·S    外祖父兄弟的儿子  → 堂舅
```

「堂」还是「表」按两个维度判断，缺一不可：

1. 旁系跳转走 `B`（兄弟）而不是 `R`（姐妹）——姐妹外嫁，子女随夫姓
2. 紧邻跳转的那一步上溯是 `F`——姓沿父亲传，这一段没跨出宗族

所以 `M·F·B·S` 是**堂舅**而不是表伯父：「堂」是站在**母亲**那边算的。

同辈层要换锚点：`M·F·B·S·S` 是我表哥，不是堂哥——他是母亲的堂侄，跟我不同宗。

## 校验

引擎附带两条独立的推理链交叉验证：枚举 1554 条路径，其中 308 条语义确定，代数与词性矛盾 0 条。
